# Calculator

Calculadora web desenvolvida com HTML, CSS e JavaScript puro.

## Funcionalidades
- Operações básicas: adição, subtração, multiplicação e divisão
- Cálculo com porcentagem
- Limpeza da expressão
- Remoção do último caractere
- Suporte a teclado do computador
- Exibição da expressão e do resultado

## Como executar
1. Abra a pasta do projeto.
2. Localize o arquivo `index.html`.
3. Abra-o em um navegador para usar a calculadora.

## Tecnologias
- HTML
- CSS
- JavaScript
